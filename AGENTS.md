# POCT Web App Guide

- This repository owns the public JeevDristi marketing, project-information, support, and download website.
- Keep the site static, fast, accessible, and deployable from generated Vite output.
- Do not publish patient data, credentials, private source details, signing keys, or private Firebase configuration.
- Release links must point to the public `iitbh-poct/poct_fw_app_releases` repository.
- Do not claim an APK, firmware image, certification, clinical validation, or production capability exists unless the corresponding public release or approved project source supports it.
- Use Bun, React, TypeScript, and Vite. Run `bun run lint` and `bun run build` before publishing.
- Use repository-local Git identity `shashankb <shashankb@iitbhilai.ac.in>` and Conventional Commits.
